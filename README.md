# KurupDevs - Telegram UserBot
# A simple, fast, and lightweight Telegram userbot
# Built with Pyrofork
#
# [![Stars](https://img.shields.io/github/stars/kurupdevs/Kurupdevs?style=social)](https://github.com/kurupdevs/Kurupdevs)

## Features

- 🚀 Fast and lightweight
- 🛡️ Anti-PM protection
- 💬 Fun commands
- 📝 Notes system
- 🎯 Spam & purge tools
- 🎨 Sticker management
- 🔧 Shell & eval access

## Environment Variables

- `API_ID` - Telegram API ID
- `API_HASH` - Telegram API Hash  
- `BOT_TOKEN` - Bot token (optional)
- `OWNER_ID` - Your user ID

## Commands

**General:**
- `.ping` - Check latency
- `.alive` - Bot status
- `.help` - Show help
- `.info` - User info

**Fun:**
- `.laugh` - Random laugh
- `.shayari` - Random shayari
- `.hack` - Fake hack
- `.magic` - Magic 8-ball

**Management:**
- `.spam` - Spam messages
- `.purge` - Delete messages
- `.approve` - Approve PM
- `.revoke` - Revoke PM
- `.restart` - Restart bot
- `.eval` - Evaluate code
- `.shell` - Run shell

**Utilities:**
- `.save/get/notes` - Notes system
- `.carbon` - Carbon code image
- `.thumbnail` - Generate thumbnail
- `.say` - Repeat text
- `.kang` - Steal stickers
- `.whois` - User lookup
